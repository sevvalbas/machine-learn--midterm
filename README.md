# Machine Learning Midterm Project

This repository contains the midterm project for the Machine Learning course, focusing on supervised classification and unsupervised clustering analyses using standard benchmark datasets.

## 📊 Project Overview
This project evaluates various machine learning algorithms on two distinct datasets:
1. **Wine Dataset**: Multi-class classification and clustering.
2. **Breast Cancer Dataset**: Binary classification (Malignant vs. Benign).

## 🤖 Models Implemented
* **Supervised Learning:**
  * K-Nearest Neighbors (KNN)
  * Decision Tree Classifier (with depth optimization)
  * Naive Bayes
  * Logistic Regression
* **Unsupervised Learning:**
  * K-Means Clustering (evaluated via Inertia, Silhouette Score, and Adjusted Rand Index)

## 📁 Repository Structure
* `machine_learning_midterm.ipynb` (or `.py`): Main source code containing data preprocessing, training, and evaluation loops.
* `six_24_runs.csv`: Consolidated raw metrics from multiple experimental runs.
* `report.pdf`: Detailed formal academic report of the project.
* `requirements.txt`: Required Python packages.
